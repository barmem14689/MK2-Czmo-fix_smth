# Cozmo-MK2 (исправленная версия)

Небольшой робот на **ESP32-C3 Super Mini** с OLED-«лицом», двумя сервоприводами и управлением через браузер по Wi‑Fi.

Основано на оригинальном проекте: [nturmose21/MK2-Czmo](https://github.com/nturmose21/MK2-Czmo).

В этой папке — рабочая версия скетча с исправлениями для **ESP32 Arduino Core 3.x**, веб-интерфейса и логики управления.

## Возможности

- Управление с телефона или ПК через браузер (без отдельного приложения)
- Кнопки «удерживай, чтобы ехать» (hold-to-move)
- Анимации эмоций на OLED (`Emotions.h`, 110 кадров)
- Движение вперёд / назад / влево / вправо и режим «wiggle»
- Вывод отладочных сообщений в Serial Monitor

## Аппаратная часть

| Компонент | Описание |
|-----------|----------|
| **ESP32-C3 Super Mini** | Контроллер и Wi‑Fi |
| **SSD1306 0.96" OLED** | Дисплей, I²C, адрес `0x3C` |
| **2× SG90 / MG90S** | Левый и правый привод |
| **Аккумулятор** | 3.7 V Li-ion / Li-Po |
| **Прочее** | Провода, корпус, 3D-детали (см. оригинальный репозиторий) |

### Подключение

| Пин ESP32-C3 | Назначение |
|--------------|------------|
| GPIO 6 | Сигнал левого серво |
| GPIO 7 | Сигнал правого серво |
| 3.3 V / GND | Питание серво и OLED |
| SDA / SCL | OLED (I²C) |

> Для C3 Super Mini стандартные пины I²C обычно **SDA = GPIO8**, **SCL = GPIO9** (если дисплей не заводится — проверьте распиновку вашей платы).

## Установка и настройка Arduino IDE

1. Установите [Arduino IDE](https://www.arduino.cc/en/software) (2.x рекомендуется).
2. **Файл → Настройки → Дополнительные URL менеджера плат:**
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. **Инструменты → Плата → Менеджер плат** → установите **esp32** от *Espressif Systems* (версия 3.x поддерживается при правильных библиотеках, см. ниже).

### Параметры платы для ESP32-C3 Super Mini

| Параметр | Значение |
|----------|----------|
| Board | **ESP32C3 Dev Module** |
| USB CDC On Boot | **Enabled** |
| Flash Size | по вашей плате (часто **4MB**) |
| Upload Speed | 921600 или 115200 |
| Port | COM-порт вашей платы |

**USB CDC On Boot** обязателен для Serial Monitor на C3 Super Mini.

## Библиотеки (важно)

### Обязательные библиотеки

Установите через **Скетч → Подключить библиотеку → Управлять библиотеками** или ZIP:

| Библиотека | Способ установки |
|------------|------------------|
| ESP32Servo | Менеджер библиотек |
| Adafruit GFX Library | Менеджер библиотек |
| Adafruit SSD1306 | Менеджер библиотек |

### AsyncTCP и ESPAsyncWebServer — только новые форки

На **ESP32 Arduino Core 3.x** старые библиотеки *me-no-dev* вызывают падение:

```
assert failed: tcp_alloc ... (Required to lock TCPIP core functionality!)
```

**Нужно:**

1. Удалить старые папки из `Документы\Arduino\libraries\`:
   - `ESPAsyncWebServer`
   - `AsyncTCP`
2. Установить ZIP (**Скетч → Подключить библиотеку → Добавить .ZIP**), в таком порядке:
   - [ESP32Async/AsyncTCP](https://github.com/ESP32Async/AsyncTCP) — версия **≥ 3.3.2**
   - [ESP32Async/ESPAsyncWebServer](https://github.com/ESP32Async/ESPAsyncWebServer) — версия **≥ 3.6.2**

**Не используйте** одноимённые пакеты из Менеджера библиотек от me-no-dev — они устарели.

### Альтернатива (без смены библиотек)

Откатить платформу ESP32 в Менеджере плат до **2.0.17** — тогда могут работать старые библиотеки, но это менее предпочтительно.

## Настройка Wi‑Fi

В файле `Cozmo-MK2.ino` укажите свою сеть:

```cpp
const char* ssid = "ИМЯ_ВАШЕЙ_WIFI";
const char* password = "ВАШ_ПАРОЛЬ";
```

Робот подключается к **существующей** домашней Wi‑Fi сети (режим STA). Телефон или ПК для управления должны быть в **той же сети**.

---

## Прошивка и первый запуск

1. Откройте `Cozmo-MK2.ino` в Arduino IDE.
2. Задайте `ssid` и `password`.
3. Выберите плату и порт (см. таблицу выше).
4. Нажмите **Загрузить**.
5. Откройте **Монитор порта**: скорость **115200**, перевод строки **NL** или **NL & CR**.

### Ожидаемый вывод после загрузки

```
.....
192.168.x.x
http://192.168.x.x/
http://192.168.x.x/
...
```

На OLED до нажатия **Start** отображается:

```
Connect to:
http://192.168.x.x/
```

---

## Как пользоваться

1. Дождитесь подключения к Wi‑Fi (точки в Serial, IP на экране).
2. На телефоне или ПК откройте в браузере адрес с OLED, например: `http://192.168.1.50/`
3. Нажмите **Start** — включаются анимации и управление моторами.
4. **Удерживайте** кнопки движения (не одиночный клик):
   - **Forward** — вперёд
   - **Backward** — назад
   - **Left** / **Right** — поворот
   - **Wiggle** — покачивание
5. Отпустите кнопку — робот останавливается.

### Поведение до и после Start

| Состояние | OLED | Сервоприводы |
|-----------|------|----------------|
| До **Start** | IP-адрес для подключения | Реагируют на команды с веб-страницы (`updateCar()` в фоне) |
| После **Start** | Анимация эмоций | Обновляются во время анимации |

## Отладка через Serial Monitor

При нажатиях на веб-странице в мониторе порта появляются сообщения:

| Действие | Сообщение |
|----------|-----------|
| Start | `WEB: /start` |
| Forward (нажатие) | `WEB: forward ON` |
| Forward (отпускание) | `WEB: forward OFF` |
| Backward | `WEB: backward ON` / `OFF` |
| Left | `WEB: left ON` / `OFF` |
| Right | `WEB: right ON` / `OFF` |
| Wiggle | `WEB: wiggle ON` / `OFF` |
| Потеря Wi‑Fi | `Wi-Fi lost` |

Если сообщений нет — см. [Устранение неполадок](#устранение-неполадок).

## Список внесённых изменений

Ниже — все правки относительно [оригинального скетча](https://github.com/nturmose21/MK2-Czmo/blob/main/Cozmo-MK2.ino).

### 1. Совместимость с ESP32 Core 3.x (среда, не код)

**Проблема:** после загрузки плата перезагружалась с ошибкой  
`assert failed: tcp_alloc ... Required to lock TCPIP core functionality!`

**Решение:** использовать библиотеки [ESP32Async/AsyncTCP](https://github.com/ESP32Async/AsyncTCP) и [ESP32Async/ESPAsyncWebServer](https://github.com/ESP32Async/ESPAsyncWebServer) вместо устаревших me-no-dev. Подробности — в разделе [Библиотеки](#библиотеки-важно).

---

### 2. Ожидание подключения к Wi‑Fi перед запуском сервера

**Было:** `WiFi.begin()` без ожидания, `server.begin()` сразу.

**Стало:** цикл ожидания `WL_CONNECTED`, вывод IP в Serial:

```cpp
WiFi.begin(ssid, password);
while (WiFi.status() != WL_CONNECTED) {
  delay(500);
  Serial.print(".");
}
Serial.println();
Serial.println(WiFi.localIP());
```

Сервер стартует только после успешного подключения.

---

### 3. Исправлен баг с IP-адресом на OLED

**Было (опасно):**

```cpp
char urlStr[32];
sprintf(urlStr, "http://%s/", WiFi.localIP().toString().c_str());
```

Временная `String` уничтожалась до использования `.c_str()` → возможна порча памяти и непредсказуемое поведение.

**Стало:** функция `showConnectedUrl()`:

```cpp
void showConnectedUrl() {
  String url = "http://" + WiFi.localIP().toString() + "/";
  showMessage("Connect to:", url.c_str());
  Serial.println(url);
}
```

---

### 4. Исправлены перепутанные кнопки Forward / Backward

**Было в HTML:** кнопка с подписью «Forward» вызывала `/backward/on`, а «Backward» — `/forward/on`.

**Стало:** соответствие подписи и маршрута:

| Кнопка | ON | OFF |
|--------|----|-----|
| Forward | `/forward/on` | `/forward/off` |
| Backward | `/backward/on` | `/backward/off` |

---

### 5. Веб-интерфейс: работа на ПК и на телефоне

**Было:** только `ontouchstart` / `ontouchend` — на компьютере кнопки не срабатывали.

**Стало:** функция `bindHold()` с обработчиками:

- `touchstart` / `touchend` — смартфон
- `mousedown` / `mouseup` / `mouseleave` — мышь на ПК

Кнопки нужно **удерживать**, а не просто кликать.

---

### 6. Упрощён и исправлен `loop()`

**Было:** смешанная логика, рискованный `sprintf`, отладочный вывод в конце цикла.

**Стало:**

- Пока `started == false` — показ URL, `updateCar()`, пауза 500 ms.
- После **Start** — при потере Wi‑Fi сообщение «Wi-Fi lost», иначе `playAnimation60fps()`.
- Ранний `return` для ясной структуры веток.

---

### 7. Управление сервоприводами до нажатия Start

**Добавлено:** вызов `updateCar()` в ветке `!started`, чтобы моторы реагировали на веб-команды ещё до запуска анимации (удобно для проверки).

---

### 8. Отладочные сообщения во всех HTTP-обработчиках

В каждый обработчик `/…/on` и `/…/off` добавлен `Serial.println` для диагностики. В том числе исправлен пропуск логов для:

- `/left/off` → `WEB: left OFF`
- `/right/off` → `WEB: right OFF`

(флаги `leftActive` / `rightActive` и раньше сбрасывались корректно, не выводился только текст в Serial).

## Устранение неполадок

### Плата перезагружается с `tcp_alloc` / `TCPIP core`

→ Установите библиотеки **ESP32Async** (см. [Библиотеки](#библиотеки-важно)). Удалите старые копии.

### Serial Monitor пустой

- Скорость **115200**
- **USB CDC On Boot → Enabled**
- Закройте монитор, загрузите скетч, откройте монитор снова
- Попробуйте другой USB-кабель (с передачей данных)

### Кнопки на странице не работают

- Устройство в **той же Wi‑Fi**, что и робот
- Сначала нажмите **Start**
- **Удерживайте** кнопку (на ПК — мышью)
- Обновите страницу после прошивки (кэш браузера)

### В Serial есть `forward ON`, но моторы не крутятся

- Проверьте питание серво (отдельное 5 V при необходимости)
- Провода на GPIO 6 и 7
- Нажали ли **Start** (после Start движение идёт во время анимации)

### OLED не включается

- Адрес I²C `0x3C`
- Пины SDA/SCL для вашей платы C3
- Общий GND
